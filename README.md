# Sentence Safari

A sentence-typing game. Type each sentence exactly (capitals, punctuation, spaces) to move the explorer past 10 animals before the 90-second clock runs out. A wrong key is never accepted and counts against accuracy.

An original implementation inspired by the idea of strict sentence typing practice. All code, sentences and visuals are new.

## Play

Open `index.html` in a browser. No build step, no dependencies.

To host it free with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Features

- 10 sentences per run, shuffled each time
- 90-second timer, WPM, accuracy and score
- Best score saved in the browser (localStorage)
- Works on desktop keyboards; respects reduced-motion settings
